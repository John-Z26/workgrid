# WorkGrid

WorkGrid 是一个用于快速梳理工作内容与工作时间的单人网页工具。

## 客户端

WorkGrid 现在是可安装的渐进式 Web 应用（PWA）：

- 支持安装到手机主屏幕或电脑桌面，并以独立窗口运行
- 首次在线打开后可离线启动，日程仍保存在当前设备的浏览器存储中
- 网页版和安装版使用同一套代码，线上版本更新后会自动获取最新资源

## 已实现

- 创建、编辑和删除工作方块
- 七种基础颜色与 15 分钟粒度的自由时长（15 分钟至 12 小时）
- 在电脑或手机上将方块拖入日历进行排期
- 手机端也可先点选方块，再点击时间格完成排期
- 今日、月、周、日四种视图
- 周、日时间轴覆盖完整 24 小时，并默认滚动到白天时段
- 待办、进行中、已完成三种任务状态
- 今日进度、计划时长、完成时长与逾期任务处理
- 周视图和日视图按真实时长显示，并以 15 分钟为单位吸附
- 重叠工作自动并排显示，桌面端可拖动底部手柄调整时长
- 手机端可在编辑面板中以 15 分钟为单位调整时长和开始时间
- 调整已排工作或移回待安排列表
- 当前视图工作时长统计与时间冲突提示
- 使用浏览器本地存储自动保存数据
- 导出 JSON 备份、导入预览、合并或覆盖恢复
- 导入前自动创建恢复点，并支持一次性撤销导入
- 为已排期工作设置开始时、提前 5 分钟至提前 1 天的提醒
- 批量修改工作状态、颜色或删除工作
- 桌面端和移动端响应式布局

## 提醒说明

WorkGrid 0.5 的提醒在应用打开或保持运行时检查。允许浏览器通知权限后会同时显示系统通知；未允许权限时仍会显示应用内提醒。完全关闭网页或应用后的可靠后台提醒，需要后续接入云端推送服务。

## 数据备份

点击页面右上角的“数据管理”图标：

- “导出备份”会下载包含全部工作方块和日程的 JSON 文件，数据不会上传服务器。
- “导入恢复”会先检查文件并展示摘要，可选择合并或覆盖当前数据。
- 每次成功导入前都会保存恢复点，可从同一菜单撤销最近一次导入。

## 本地运行

```bash
npm install
npm run dev
```

打开终端显示的本地地址即可使用。

## 正式构建

```bash
npm run build
```

构建结果位于 `dist` 目录，可部署到任意静态网站托管服务。
