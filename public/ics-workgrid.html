3导入到 WorkGrid
  1. 点击「生成 WorkGrid 备份并下载」，得到 workgrid-backup-*.json 文件
  2. 浏览器打开 WorkGrid：zhoubx634.github.io/workgrid
  3. 点击右上角菜单 → 导入恢复 → 选择刚下载的 json 文件
  4. 选择「合并导入」（与已有日程合并），确认后完成；想恢复原样可点「撤销上次导入」
隐私与机制：本工具为纯前端，所有解析、转换都在当前页面本地完成，不上传任何数据；它只生成 WorkGrid 官方支持的备份 JSON，不会改动 WorkGrid 本身。
展开窗口：重复课表只展开「今天起未来 N 天」窗口内的课程（窗口外的不生成，学期中途导入也只会得到未来课程）。
重复导入：同一课表重复导入时，每个任务由「来源 UID + 发生时刻」确定性生成相同的编号与创建时间，WorkGrid 的合并导入会按编号自动跳过已存在的项，不会产生重复卡片。
依赖：重复规则展开使用 jsDelivr CDN 加载的成熟库 rrule.js，需联网使用；课表数据仍完全在本地处理。
